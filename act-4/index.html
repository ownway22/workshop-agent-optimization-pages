    Act 4：擴大改善規模¶

    目標¶

    給定相同的 Rubric Evaluator 評分表（scorecard）與測試題目，使用 Agent Optimizer 探索 Agent 的候選設定，並提供候選方案。秉持 改版有理由、審查有依據、決策可追溯，協助 AI 開發者決定是否採用候選方案。

    完成條件¶

    • 理解 Agent Optimizer 的起點、候選方案與其處理的 Insights 問題。

    步驟¶

    1．檢視 Optimize 的候選方案與評估結果¶

    進入您的 Foundry project（proj-opt-g0*），依序點選 Agents → contoso-travel → Optimize，選擇狀態為 Succeeded 的 Run ID，檢視起始 Agent 設定與候選方案的 Score、Avg tokens、Avg latency 等資訊。

    圖 1：Optimize 介面參考；請一起查看分數、Token 用量與平均延遲，實際結果以本組畫面為準。
