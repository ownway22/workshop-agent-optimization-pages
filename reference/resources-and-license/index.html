    資源與授權¶

    這個網站將原 BRK330 四幕流程改編為第二場分組實作。原始教材提供學習脈絡；本場的模型、題量、環境與可執行命令，以講師正式交付並完成驗證的版本為準，不直接照搬上游部署流程。

    Microsoft Learn 查找官方概念、功能前置條件與引導式學習。
    Microsoft Foundry 社群 延伸討論；分享前先移除個資、憑證與敏感追蹤記錄。

    官方技術文件¶

    • Microsoft Foundry：執行階段、專案、模型與評估。
    • Insights：以執行追蹤記錄找出反覆問題。
    • Rubric Evaluator：建立品質與政策評分契約。
    • Model Router：動態選擇模型。
    • Agent Optimizer：候選產生與比較。
    • GitHub Copilot：以 Agent 與工具協助開發流程。
    • Fine-tuning 範例：追蹤記錄與工具呼叫的訓練資料。

    模型、區域、配額、價格與預覽／正式推出狀態會改變。原始文件用於理解功能；本場操作仍以已驗證的交付版本與本組放行範圍為準，不因官方範例可用就自行更換模型、地區或工具版本。

    原版延伸閱讀：不在本場執行¶

    原指南另含模型微調、Quality Router、v3-router 及工具／資料修正路線。這些是課後理解完整方法的參考，不是本場共用環境的選做命令；本場不部署其模型、不提交訓練，也不以原版分數取代本組結果。

    原版的 Codespaces、GPT-5.4 系列、Developer tier、完整 setup／teardown 與舊 CLI 畫面可能和本場不同。閱讀原文時先分清楚「原版示範」與「本次活動適配」，不要在既有 VM 或共用資源群組直接照做。
