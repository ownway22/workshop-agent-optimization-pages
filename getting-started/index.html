    準備¶

    環境說明¶

    接續 Agentic Factory (Lab 1)，沿用 同一台 遠端桌面與您的學員帳號，但切換至第二場專用的 Foundry prject 和 VS Code 工作目錄。



    完成條件¶

    • 進入指定的遠端桌面環境 (透過 RDP)，並開啟第二場專用的 Foundry prject。

    步驟¶

    確認本組環境後，沿著各 Act 編號的步驟操作並理解其中的意涵。

    頁面 主軸 核心技術
    Act 1：先讓它運作 差旅助理能幫使用者完成哪些事？ Foundry Hosted Agent
    Act 2：找出表現不佳的地方 哪些失誤會造成重查、重做或交接不清？ Agent Insights
    Act 3：讓它更好 更快或更省，是否犧牲了必要品質？ Rubric Evaluator、Model Router
    Act 4：擴大改善規模 如何多做嘗試，又保留人的掌控？ Agent Optimization
